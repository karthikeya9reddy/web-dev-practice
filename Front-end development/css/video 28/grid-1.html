summary of the video 1. Line-Based Placement (The First Approach) This method defines the structure using numerical lines to position items. display: grid (1:43): The base property to activate the grid layout on a parent container. grid-template-columns (2:18, 8:41): Sets the number and width of columns. You can use fixed units (pixels) or relative units. grid-template-rows (8:56): Similar to columns, this property defines the height of individual rows. Grid Lines (4:24, 6:49): The vertical and horizontal lines that form the grid. These can be identified by positive numbers (1, 2, 3...) or negative numbers (-1, -2...) to count from the end. grid-row & grid-column (9:43, 11:06): Properties placed on items to define their span (e.g., 1 / 3 starts at line 1 and ends at line 3). Named Grid Lines (13:10): You can assign custom names to lines (e.g., [first] 120px [second]) for easier reference instead of just using numbers. Essential Terminology Grid Cell (4:33): The basic unit (one box) formed by the intersection of one row and one column. Grid Track (5:01): The space between two adjacent grid lines (representing a full row or a full column). Grid Area (5:18): A rectangular grouping of one or more grid cells. fr Unit (22:27): A flexible fractional unit representing a share of the available space in the container. gap (24:01): Controls the spacing between grid items, including row-gap and column-gap. justify-items / align-items (25:25): Controls the alignment of content inside each individual cell (horizontal and vertical). justify-content / align-content (29:05): Aligns the entire grid block within the parent container if the grid is smaller than the container size. align-self: Controls the alignment of an item along the block axis (vertical alignment) inside its cell. justify-self: Controls the alignment of an item along the inline axis (horizontal alignment) inside its cell. repeat() syntax (27:35): A shortcut to define multiple tracks (e.g., repeat(4, 1fr) creates 4 equal columns). minmax() (27:52): Sets a range for track size, ensuring a minimum size while allowing flexibility up to a maximum value.
